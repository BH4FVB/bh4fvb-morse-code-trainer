# BH4FVB电码练习器

一款面向业余无线电爱好者的轻量级摩尔斯电码听抄训练工具。

## 功能

- 40节渐进式基础课程，覆盖字母、数字与常用标点
- 业余无线电通联组合与Q简语进阶训练
- 任意字符自由播放
- 字符速度、有效速度、音调与分组调节
- 20字符随机听写、暂停、重播与自动评分
- 桌面和手机布局
- 浏览器实时合成音频，无需服务器或账号

## 在线使用

[https://bh4fvb.github.io/bh4fvb-morse-code-trainer/](https://bh4fvb.github.io/bh4fvb-morse-code-trainer/)

```bash
pnpm install

```
